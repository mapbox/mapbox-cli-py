# mapbox-cli-py

> [!WARNING]
> **This is the legacy Mapbox CLI and is no longer maintained.** The current Mapbox CLI is [mapbox/mapbox-cli](https://github.com/mapbox/mapbox-cli). Install it with:
>
> ```
> brew install mapbox/tap/mapbox
> ```
>
> See [cli.mapbox.com](https://cli.mapbox.com) for other install options.

The documentation for 0.8.0, the last release before this CLI was archived, is [here](https://github.com/mapbox/mapbox-cli-py/blob/0.8.0/README.md). It is kept for reference and is no longer updated.
